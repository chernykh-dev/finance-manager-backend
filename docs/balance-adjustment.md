# Корректировка баланса счёта

Баланс счёта меняется только операциями. `PUT /api/v1/account/{id}` меняет имя и валюту; поле `balance`, если
его прислать, игнорируется.

Ручная правка баланса — отдельный запрос «установить баланс в X»:

```http
POST /api/v1/account/{id}/balance-adjustment
Idempotency-Key: <uuid операции>

{ "balance": 250.00, "dateTime": "2026-11-02T10:00:00Z", "comment": "нашёл в кармане" }
```

| Поле | | |
|---|---|---|
| `balance` | обязательно | целевой баланс счёта |
| `dateTime` | необязательно | дата операции-корректировки, по умолчанию — сейчас |
| `comment` | необязательно | комментарий к операции |

Сервер под блокировкой счёта считает разницу с **текущим** балансом и создаёт обычную операцию в системной
категории «Корректировка»: доход, если баланс растёт, расход — если уменьшается. Клиенту не нужно знать
актуальный баланс, параллельные операции по счёту не теряются.

Ответ `200`:

```json
{
  "account": { "id": "…", "name": "…", "balance": 250.00, "…": "…" },
  "transaction": { "id": "…", "accountId": "…", "categoryId": "1d6b623d-48ec-41fe-96a8-d6a427a5cdea", "amount": 150.00, "…": "…" }
}
```

`transaction` — `null`, если баланс уже был равен запрошенному (операция не создаётся).

Ошибки: `404` — счёта нет или он чужой; `400` — счёт удалён.

Системные категории (фиксированные id, есть в `GET /api/v1/category`; в выборе категории для обычной операции
их стоит скрывать):

| Категория | id | `isIncome` |
|---|---|---|
| Корректировка (доход) | `1d6b623d-48ec-41fe-96a8-d6a427a5cdea` | `true` |
| Корректировка (расход) | `674a6f9c-1e92-41ed-bdae-7c0c4909bda8` | `false` |
